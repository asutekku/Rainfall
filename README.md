
# Rainfall - a Cyberpunk game

> RPG game with setting from Cyberpunk 2020 tabletop role playing game.

Welcome to the streets of Evolvia. The once great city now ridden
 with drug dealers, gangs and loafers. You are one one of them.
 
 To run the game, install [Bun](https://bun.sh) and build:

 ```sh
 bun install
 bun run build        # bundles src/ts/index.tsx -> dist/bundle.js
 ```

 Then open `index.html`. Other scripts: `bun run watch` (rebuild on change),
 `bun run typecheck` (tsc), `bun run lint` (tslint).
